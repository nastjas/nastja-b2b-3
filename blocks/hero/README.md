# Hero

Full-width banner block used at the top of a page. A background image is
placed absolutely behind the content; headings and text render on top.

## Content structure

One row with a single cell containing (in order): an image (`picture`),
optional eyebrow paragraph, an `h1`, an optional description paragraph and
an optional call-to-action link.

## Variants

### `welcome` (MS Motorservice)

Add `welcome` to the block (author it as `Hero (welcome)`). Adds:

- a navy → blue brand gradient overlay above the image for text legibility;
- left-aligned white heading, uppercase eyebrow and description;
- a red (`--ms-red`) call-to-action button on the CTA link.

Colors come from the brand tokens in `styles/brand.css`.
